**Cover Vice** is an offline web app that turns your photos into GTA-style
cover art: a multi-panel collage with angled diagonal dividers and white
panel frames, one larger hero panel, every photo pushed through a
saturated comic grade, a huge condensed title across the top and a caption
bar along the bottom. All artwork is generated by the app's own canvas
code — no game logos, characters or fonts are used. The display font is
Anton (SIL Open Font License, bundled in `app/fonts/` with its license).

## Features

- **Real editor** — load photos from your machine (file picker or
  drag-and-drop; photos never leave the device), or start from the two
  built-in samples. Click a panel to select it, click a photo to assign it,
  drag on the preview to reposition, and fine-tune with zoom / move
  sliders.
- **Two layout modes** — a different photo per panel, or "one photo,
  sliced": a single image drawn continuously across every panel so it
  flows under the diagonal cuts. A spread button fans one photo across all
  panels with varied crops.
- **Three presets** — Sunset Vice (orange/pink), Neon Nights
  (magenta/cyan) and Gold Hour (amber/teal) re-skin the grade, frames,
  title and caption bar.
- **Three exact sizes** — 1080×1080, 1080×1350 and 1920×1080, with the
  panel layout adapting to each aspect ratio.
- **True export** — the Export button renders at the exact pixel size to
  an offscreen canvas and downloads a PNG. Preview, screenshot mode and
  export all run through the same `drawCover` function in
  `app/src/cover.js`, so the preview never lies.
- **Zero network** — static files only, no build step; `app/index.html`
  works fully offline.

## Run it

```
node serve.ts
```

then open http://localhost:8080 in a desktop browser.

## Screenshots

`shots.json` + `take-screenshots.mjs` regenerate the four JPEGs in
`screenshots/` by driving headless Chromium against the app's
deterministic `?shot=` URL modes (`?shot=cover&size=…&photo=…&preset=…`
renders only the finished cover through the export code path;
`?shot=editor&photo=…` opens the editor with a sample loaded).

## Layout of this repo

- `app/` — the web app (`index.html`, `style.css`, `src/cover.js` the
  composition/grade/export engine, `src/main.js` the editor wiring,
  `samples/` built-in photos, `fonts/` Anton + OFL license).
- `main.ts` — the make.fun entry point: copies `app/` and `screenshots/`
  to the output directory and writes `dossier.json` via the vendored
  library in `vendor/`.
- `serve.ts` — a tiny static server for trying the app locally.
